# Tegnelia & DeBose, APC — EmailMyLawyer.com

Criminal defense law firm website for San Diego. Built with **Next.js 15 (App Router)**,
**Tailwind CSS v4**, and **Framer Motion**. Dark navy/gold design system, 18 pages, full
on-page SEO (per-page metadata, JSON-LD schema, sitemap.xml, robots.txt).

## Run locally

```bash
npm install
npm run dev      # http://localhost:3000
```

```bash
npm run build && npm start   # production build + serve
```

> Note: don't run `next build` while `next dev` is running against the same `.next`
> directory — it corrupts the build output. Stop dev first (or build in a clean checkout).

## Structure

| Path | What |
|---|---|
| `app/` | Routes (one folder per page) + `layout.tsx`, `sitemap.ts`, `robots.ts` |
| `app/[slug]/` | Dynamic template rendering all 9 practice-area pages |
| `components/` | Nav, Footer, hero, CTA band, FAQ accordion, reviews, forms, schema, etc. |
| `lib/` | Content data: `site.ts` (NAP), `practice-areas.ts`, `cities.ts`, `reviews.ts`, `faqs.ts` |
| `public/images/` | Drop real photos/logo here — see `public/images/README.md` |

All copy lives in `lib/` so text edits don't require touching components.

## Pages (18)

Home, Attorney, Practice Areas hub, Testimonials, Contact · 9 practice-area pages
(DUI, Domestic Violence, Drug, Theft, Assault & Battery, Weapons, White Collar, Felony,
Expungements) · Service Areas hub, San Diego · Privacy Policy, Disclaimer.

  (4.4★ / 22) lives in `lib/site.ts` and feeds the trust strips and `AggregateRating` schema.
  Refresh these periodically as new reviews come in.

## SEO notes

- One `<h1>` per page, unique `<title>` + meta description, canonical + OG tags.
- Schema: `LegalService` (home), `Attorney` (bio), `LocalBusiness` (San Diego + contact),
  `FAQPage` (every page with an accordion), `BreadcrumbList` (all inner pages).
- `sitemap.xml` and `robots.txt` are generated by `app/sitemap.ts` / `app/robots.ts`.
- No competing SEO plugins added, per the third-party-SEO constraint.
